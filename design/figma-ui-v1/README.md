# 千绵美学 · Figma UI 首版

首页：https://www.figma.com/design/DdJzWUCAaR8FscwCjLzYz9?node-id=8-20

依据：已确认的 `design/prototype-v1` 原型。店长日常业务优先，平台运营独立标注。店名为「千绵美学」，首页不保留“先看经营，再处理门店事务”的解释。

## 交付范围

- 31 个原型模板已覆盖；日常业务 38 张画板包含编辑、页签与扣次后余额状态。
- 18 张补充画板：空、加载、错误、无可用卡、短信、权限、余额冲突、筛选、分页、表单错误、提交中、账号交付与 360/430 尺寸样例。
- 4 张平台运营范围画板，明确标记演示且禁用提交。
- 39 个颜色和布局变量、7 个文字样式；可复用按钮、输入、列表、次卡、导航、图标与提示组件。
- 核心扣次流程：首页 → 会员 → 李晓妍 → 水光焕肤次卡扣次 → 核对 → 结果 → 扣次后会员档案（3 次）。

## 验证与限制

日常业务文字边界检查无越界，无残留制作占位。63 条导航跳转目标有效。主文字、辅助文字、按钮与状态文字的主要配色对比度均超过 4.5:1。会员列表在 360/430px 检查长名字与未填写手机号。

Figma 表单为视觉稿，核心流程使用预设数据；未全部接通的表单与高级筛选不表示真实可保存。协议正文、权限、验证码、文件上传、短信投递、并发余额与数据提交仍需实际服务联调。设计环境使用 Noto Sans SC，开发沿用系统中文字体并复核换行。其他页面的设备、键盘和安全区域需实现时继续验证。

源码应用界面尚未按本稿改造。`figma-state.json` 保存真实页面和节点 ID，供后续继续编辑。
