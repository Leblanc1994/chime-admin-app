## 变化

- 首页经营数据开放排版，减少白卡重复；主要操作、提醒行、趋势采用不同层级。
- 暖灰底、梅紫操作色、店铺字标、下划线页签形成一致的视觉语言。
- 会员采用紧凑分隔行，区别持卡、低余次和失效状态。
- 档案加强姓名和余次；扣次为深色主要按钮，开卡与管理降为次要操作。

## 自评与验证

逐页检查三张 390×844 画板，以及会员列表和档案的 360px 样例。文字边界无越界。辅助文字至少 12px；主要按钮至少 44px。窄屏长姓名采用单行省略，并展示缺失手机号。

主要配色对比度：正文/背景 13.54:1，辅助文字/背景 4.75:1，主要按钮文字/底色 9.39:1。未声称完整无障碍评估。

视觉自评：重复容器减少，业务动作层级更清楚；品牌识别仍属方向验证，店铺标记不是正式 Logo。数据少时列表保留空白，不添加虚构业务填充。可继续评估真实数据密度与长期使用体验。
