# 千绵美学 · V3 品牌视觉稿

预览：http://127.0.0.1:9913/design/figma-ui-v3/#home

本版依据用户提供的 BeautyOS 美业 App 参考图，重做紫色品牌区、半透明曲面装饰、白色信息卡片、彩色业务图标、会员摘要和次卡余次层级。沿用已确认的店长日常业务结构与四个主导航，平台运营单独标记。

## 页面

首页、会员列表、会员档案、工作台、我的，以及扣次填写、确认、结果、消费查询。补充表单展示同一视觉体系：会员资料、开卡、散客消费、个人资料与账号信息。主导航上方可切换单页或五页总览。

## 演示边界

这是独立视觉预览，尚未替换正式业务界面；不连接后台、不保存业务数据。

会员搜索、分类与档案可交互。李晓妍的水光焕肤次卡接通一次扣减 1 次的演示：余次 4 → 3，列表摘要 6 → 5，首页今日消费 2 → 3、今日扣次 1 → 2、近七日消费 3 → 4；消费记录与流水追加样例记录。重新加载页面会恢复初始数据。其他提交入口提供视觉预览提示。

没有扩展参考图中的收银、储值、预约、库存或 AI 助手。
