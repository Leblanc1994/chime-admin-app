## 本轮改动

采用用户提供的 chime.png。原文件保存在 assets/chime-original.png，透明标识和字标由原图裁切提取，未重绘图形。保留紫色为操作色，以暖金标识、柔白背景、柔和姓氏头像建立品牌层次。

首页将数字提醒改为具体会员关怀，增加最近消费信息，趋势图移到下方；会员列表改为连续行，突出余次和次卡状态。会员档案将来源放回资料信息，以品牌次卡强调余次、有效期和操作。工作台及我的采用轻量页头，减少重复的大面积紫色装饰和白色卡片。

扣次确认补齐当前余次、扣减后余次、消费时间、备注和短信选择；返回修改保留输入。首页开卡先选择会员。
