## 页面与弹层规则

- 底部弹层：补次、调整余次、重置员工密码、扣次核对、日期筛选；校验与提交中作为相应弹层的状态。
- 居中确认弹窗：次卡停启用/作废、会员删除、消费删除、员工停启用、退出登录。
- 独立页面：会员建档、开卡、消费登记/编辑、员工建档等长表单，以及需要持续查看的列表和详情。
- 弹层保留原业务背景，背景不接受操作；关闭返回原上下文。扣次核对关闭后保留填写内容。表单失败保留输入，提交中禁用重复操作。
- 危险操作明确列出对象、影响和取消入口；作废不提供恢复能力。

## Figma 与交互范围

62 个设计状态均为原生可编辑内容，复用 156 个现有组件实例，中文统一 Noto Sans SC。新增颜色变量限定在 V4 补页范围。组内建立 54 处关键原型连接，包含打开 Overlay 与关闭；跨分组操作及数据变化使用本地交互样例评审。长表单在画布上展开便于交付，实际设备预览使用内容滚动和底部操作区。

预览只使用内存样例数据，刷新恢复。返回已定稿主页会进入独立 V4 预览，两份演示不共享账本数据。协议仅保留阅读版式，正式正文沿用后台配置。平台开通、切换、续期和方案管理仍标为待接入。
