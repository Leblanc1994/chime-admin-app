# CHIME 产品原型 v0.1

日期：2026-10-19。范围：店长日常业务为主，平台运营单独标注。

本原型根据当前项目的路由、页面、表单校验和服务调用整理，供信息架构、业务流程和字段评审。它不是最终 UI，也不意味着对应后端已经通过验收。主应用页面没有因本原型而改版。

## 交付内容

- `index.html`：31 个页面 / 状态的可点击灰度原型。首页、会员、工作台、我的保留四个主入口。
- `preview.png`：原型工作区截图。
- `SPEC.md`：现有能力、结构建议、流程与验收规则。
- `FIGMA-HANDOFF.md`：进入 Figma 的文件组织、设计任务与交接边界。
- `figma/*.svg`：390px 宽的矢量线框页面，可直接导入 Figma；文本与图形保留为 SVG 对象。
- `figma/00-flow-map.svg`：信息架构与关键业务路径。
- `figma/00-wireframe-overview.svg`：全页面总览。
- `figma-import.zip`：以上矢量稿打包。

## 浏览方法

在此目录开启普通静态网页服务后打开 `index.html`。不依赖项目安装、账号或后端。

```sh
python3 -m http.server 9911 --bind 127.0.0.1 --directory design/prototype-v1
```

从项目根目录执行后访问 `http://127.0.0.1:9911/`。也可直接打开本地 HTML 文件使用主要交互；Markdown 文档的浏览效果由查看器决定。

左侧切换页面；中间点击手机里的操作；右侧查看本页目标、实现来源和待确认事项。右侧有扣次、新会员与开卡、散客消费、员工账号四条流程入口。

“查看状态”支持正常、加载、空数据和错误。列表类页面展示对应内容状态；表单类页面在“加载失败”状态下点击提交，展示失败保留与重试。失败后切回“正常”可重试。表单无需输入真实个人资料或密码。刷新或“重置演示”恢复初始数据。

## 已验证

浏览器中验证扣次校验、提交失败与重试、演示余额和记录同步、短信排队状态、新增会员并开卡、散客消费新增编辑删除、员工新增停用，以及各页面的导出与布局。更多边界规则见 `SPEC.md`。

## 本版刻意保留的边界

- 全部姓名、电话、统计与记录均为演示数据，不访问业务 API，不存储到浏览器持久缓存。
- 没有充值、预约、商品、支付、退款或收款码流程。
- 平台运营页保留结构，涉及真实变更的操作禁用。
- SVG 不包含浏览器交互，导入 Figma 后需要建立原生组件、Auto Layout、变量和连线。
- 当前会话没有可直接编辑 Figma 文件的连接。本交付是 Figma 设计输入，不是已创建的 Figma 高保真设计稿。
