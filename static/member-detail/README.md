# 会员档案设计资源

来源：[BeautyOS Ardot 设计文件](https://ardot.tencent.com/file/724279249184238)。

- 03 会员档案：画板 `3:813`，390 × 770。
- 04 次卡账户：画板 `3:996`，390 × 713。
- 05 次卡流水：画板 `3:1054`，390 × 907。

`back.svg`、`chevron.svg`、`card.svg`、`deduct.svg`、`add.svg` 按原稿的线条图标绘制。会员头像复用会员列表的现有资源，实际头像优先。字体复用 `static/css/design-font.scss`，文字包含在 `static/home/noto-sans-sc.woff2` 的子集中。

设计以 390px 为基准，按 `750 / 390` 换算 rpx。顶部留出设备状态栏区域，不绘制模拟时间或信号。会员档案使用自定义导航，避免重复标题栏。

## 功能保留

三个画板继续由现有标签页承载，并保留“短信日志”第四个标签；消费类型与流水类型的额外筛选可以横向滑动。记录行的箭头展开现有“编辑、删除”操作。开卡、扣次消费、新增消费、补次、手调、启用／停用、作废沿用原有处理函数和状态条件，表单、分页、短信开关及接口参数保持原有逻辑。

页面显示接口真实数据，0 次与 0 张卡保持为 0；不会用设计稿示例填充记录。消费记录显示实际卡名，不额外拼接固定的 680。

## 验证

已检查 390px 与 375px 视口、四个标签、消费记录与流水筛选及空状态、短信状态筛选、档案刷新、编辑回填、所有可用操作表单及删除／停用／作废确认框的打开与取消、滚动底部和直接访问后的返回列表。H5 构建通过。未提交余额调整、开卡、消费、删除或短信发送操作；当前样例仅有一张生效卡和少量记录，启用与多页加载保留原有逻辑，未执行真实变更验证。
