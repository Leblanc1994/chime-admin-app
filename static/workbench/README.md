# 工作台设计资源

来源：用户提供的 [BeautyOS Ardot 设计文件](https://ardot.tencent.com/file/724279249184238)，工作台画板 `3:1382`，390 × 859px。

- `chevron.svg`、`chevron-white.svg`：依据原稿绘制的菜单和门店信息箭头。
- 字体复用 `static/home/noto-sans-sc.woff2`，字体子集包含首页、会员列表、工作台、我的和底部导航文案。
- 头部采用原稿四段水平渐变；182px 头部、70px 菜单行、12px 卡片圆角通过 `750 / 390` 转换为 uni-app 的 rpx。

页面保留现有六个菜单路由和门店入口，头像文字使用现有门店名称首字，用户昵称使用现有登录信息。设备状态栏由系统提供，H5 不绘制模拟时间、信号或电量。
